# 🍰 Ifa's Sweet Cakery — Toko Kue & Patisserie Online

Website toko kue modern, estetik, dan responsif yang dibuat khusus untuk **Ifa's Sweet Cakery**. Dilengkapi dengan katalog produk pilihan, keranjang belanja interaktif, dan integrasi pemesanan langsung ke **WhatsApp**.

---

## ✨ Fitur Utama

- **🎀 Desain Modern & Estetik**: Tampilan bernuansa *pink pastel*, putih bersih, dan krem hangat dengan tipografi elegan.
- **📱 Responsif**: Tampilan tetap rapi dan nyaman digunakan di smartphone (HP), tablet, maupun laptop/desktop.
- **🍰 Katalog 8 Varian Kue**: Menampilkan foto berkualitas tinggi, badge kategori, deskripsi, dan harga kue.
- **🛒 Keranjang Belanja Dinamis**:
  - Menambah kue ke keranjang dengan tombol instan.
  - Mengatur jumlah pesanan (`+` / `−`) atau menghapus item.
  - Total harga dan jumlah item dihitung secara otomatis (format Rupiah).
- **📲 Checkout Pesanan via WhatsApp**:
  - Tombol **"Pesan via WhatsApp"** yang otomatis menyusun pesan format rapi berisi nama pemesan, daftar kue yang dipilih, jumlah, subtotal, total harga, dan catatan khusus.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/sitinurhanifa0623-dot/toko-kue-ifaa.git
   ```
2. **Buka folder proyek di VS Code.**
3. **Jalankan dengan Live Server:**
   - Klik kanan file `index.html` lalu pilih **"Open with Live Server"**.
   - Website akan terbuka di browser Anda (`http://127.0.0.1:5500/`).
